## 📊 📑 本プロジェクトの結論サマリー（採用担当者向け・4ステップ解説）

*   **① 課題 (Problem)**: 商品取扱高は前年同期比（YoY）で堅調に成長しているが、その成長を支える内部のKPI（客数と単価のどちらが売上に貢献しているか）の構造的ボトルネックがブラックボックス化していた。
*   **② 分析 (Analysis)**: 公式情報を参考に設計した分析用の擬似データを定義し、Python（Pandas）を用いた要因分解パイプラインを構築。商品取扱高を「年間購入者数（成長率）× 1人あたり年間購入金額（成長率）」の複利ロジックに分解して分析。
*   **③ 結果 (Result)**: 取扱高の成長は**年間購入者数（アクティブ客数）の＋7.8%に達する急激な伸び**がカバーして牽引している一方、ユーザー1人あたり年間購入金額の寄与度は-0.2%から-3.8%へ低下していることを確認した。
*   **④ 示唆 ＆ 改善提案 (Insight & Proposal)**: 年間購入者数が増加する一方、1人あたり年間購入金額は低下しており、顧客1人あたりの購買金額には改善余地があることが分かった。さらに、1人あたり年間購入金額の低下には「購入点数/人」と「1点あたり購入価格」の双方の低下が見られた。今回のKPIデータだけでは具体的な原因までは特定できないため、商品構成や購買行動、価格帯、プロモーション等を追加分析する必要がある。施策仮説として、関連商品・コーディネート提案による「合わせ買い」を促進し、購入点数/人および1人あたり購入金額の改善を目指す。施策実施後はA/Bテストにより効果を検証する。
